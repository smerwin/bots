# notes/

One new file per finding or run write-up: `<issue>-<slug>.md` (e.g.
`341-fleet-invite.md`) or `<date>-<slug>.md` (e.g.
`2026-08-25-wingman-first-live.md`). New files never conflict, which is the
point — see `COORDINATION.md` rule 2.

Consolidating notes into `CLAUDE.md` / `WINGMAN.md` / `FINDINGS.md` is its own
claimed, single-machine task; the consolidation PR deletes the notes it folded
in, so what remains here is what has not been folded yet.
